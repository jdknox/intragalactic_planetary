# Intragalactic Planetary
Plan birthday celebrations on every planet.

## Live Demo
- [Planetary Birthday Calendar](https://jdknox.github.io/intragalactic_planetary/)

## What You Can Do
- Add friends one at a time or paste a list to import them.
- See each friend’s upcoming birthdays on Earth, Mars, Jupiter, and more.
- Explore colorful charts showing the next year, decade, and century of celebrations.
- Filter by planet or jump to a specific date to plan ahead.

## Use It Yourself
1. Open `index.html` in any modern web browser.
2. Add birthdays and start exploring.

All information stays in your browser; nothing is uploaded or stored online.
